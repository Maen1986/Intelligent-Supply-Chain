# ISC — Supplier Lifecycle Governance: `docs/`

This is the first `docs/` folder committed to this repository. It exists to close a
recurring, disclosed gap: reference material (design briefs, worked examples) that
previously lived only in chat history and a contributor's local device folder, with no
copy in the repository itself — the same failure mode that made an earlier `auth.ts`
finding "partly unrecoverable," and exactly what this folder was created to fix (see the
Site Map registry entry for this item's close-out).

## Contents

- **`ISC_SI_Scope_Expansion_Sourced_Design.md`** — the sourced design brief for the
  Supplier Lifecycle Governance build (Items 1-7). Previously existed only as chat
  content and a local file on the platform owner's device; committed here so any future
  session (with or without a device link) can read it directly from the repository
  itself, per this item's explicit close-out requirement.
- **`SI_Supplier_Lifecycle_Governance_Item3_PreQualASL_Worked_Example.md`** — the
  worked-example, stress-test, and QA record for Item 3 (Pre-Qualification & ASL),
  required by this project's standing rules (`isc-standing-rules`, Rule 6).

## Convention going forward

Every future Supplier Lifecycle Governance item (Onboarding, Periodic Evaluation,
Second-party Audits, Blacklist/Offboarding) ships its own worked-example doc into this
same folder as part of that item's close-out — not batched later, not left only in chat
— per the standing discipline in `ISC_SI_Scope_Expansion_Sourced_Design.md` section 4.
