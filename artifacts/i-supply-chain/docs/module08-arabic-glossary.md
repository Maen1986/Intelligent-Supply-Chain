# Module 08 — Arabic Terminology Glossary

Prepared Round A.2, 22 Oct 2026, in response to the owner's own Arabic QA review of Round A.1's output (finding F2). This is the single approved Arabic rendering for each recurring Module 08 term. A guard test in `supplierLocalContentEligibility.test.ts` fails if a banned term from this glossary reappears in any `sourceNoteAr`.

| English term | Approved Arabic | Why / source |
|---|---|---|
| Scoring / to score / scoring formula | `احتساب` / `صيغة الاحتساب` / `يُحتسب` | `تسجيل` means registration/enrollment in Arabic, not scoring — a real mistranslation the owner's review caught. `احتساب` (calculation/reckoning) is the correct term for a points or percentage formula. |
| Registration (a supplier registering with a portal or authority) | `تسجيل` / `التسجيل` | Kept — this is the one context where `تسجيل` is the right word. Used only where a supplier is genuinely registering (a portal sign-up, a national registration record, a login), never for a scoring mechanism. |
| Gap (missing published information) | `فجوة في المعلومات المنشورة` | `ثغرة` means a loophole or security vulnerability — wrong register for "the regulator hasn't published a formula yet." |
| Modeled / calculated independently (of a computation this platform runs) | `يُحتسب` / `محتسب` / `محسوب` (+ `بشكل مستقل` or `بشكل منفصل` where useful, never both together) | `مُنمذَج` is a calque of the English "modeled" with no natural Arabic reading. The platform computes (`يحتسب`) a result; it doesn't "model" one in Arabic. |
| For reference only / not calculated | `للاطلاع فقط` | `للعِلم فقط` is a stiff, bureaucratic calque ("for knowledge only"). `للاطلاع فقط` ("for review/reference only") is the natural customer-facing phrase. |
| Parenthetical aside / list separator in flowing prose | Arabic em dash `—`, a colon `:`, or a comma `،` | Never an ASCII double hyphen `--`, which does not belong in Arabic typography and can visually scramble under RTL rendering next to Latin/numeral runs. |
| Combining two percentages (e.g. "10%+10%") | `١٠٪ إضافة إلى ١٠٪` (spelled out) | A bare `١٠٪+١٠٪` scrambles under RTL rendering next to the ASCII `+`. Spelling out "in addition to" avoids the collision entirely. |
| A compound English-style modifier (e.g. "government-industrial agreements") | A natural Arabic construction, e.g. `اتفاقيات قطاعية بين الجهات الحكومية والقطاع الصناعي` | `حكومية-صناعية` (hyphenating two Arabic adjectives) is not natural Arabic; Arabic expresses the same relationship with `بين` (between) or a genitive construction. |
| Local Content Value / ICV | `القيمة المحلية (ICV)` at first use in a given note, then `ICV` alone | Acronym expanded once per note, consistent with how LIKT, PTLC, LCGPA and EDIP are each expanded at their own first mention. |

## Official Arabic names of issuers — verification status

Checked by web search against each issuer's own materials during this round (22 Oct 2026):

- **LCGPA** (Saudi Arabia) — `هيئة المحتوى المحلي والمشتريات الحكومية`. Confirmed: this exact Arabic name is used consistently across LCGPA's own recruitment postings and multiple independent Saudi job-board/news mirrors. Already used correctly throughout this file.
- **PTLC** (Oman) — `هيئة المشاريع والمناقصات والمحتوى المحلي`. Confirmed directly via Oman Daily's (omandaily.om) own coverage of the authority under this exact name. Already used correctly throughout this file. **Resolved, Round A.3 D6 (22 Oct 2026):** the open question in the note above (whether PTLC is a renaming of the Tender Board itself, or of an internal secretariat) is now settled by reading Royal Decree No. 57/2025's own Arabic text directly (qanoon.om/p/2025/rd2025057/). Article 1 renames only the Tender Board's **General Secretariat** (`الأمانة العامة لمجلس المناقصات`) to PTLC; Article 4 confirms PTLC's role is to support/assist the Tender Board (`معاونة مجلس المناقصات`), so the Board itself continues as a distinct body; Article 8 substitutes the old Secretariat/Secretary-General titles with PTLC's own wherever they appear in other legislation. omandaily.om's 24 Jun 2025 report independently corroborates the same renaming-of-the-Secretariat framing. `om-mandatory-list`'s customer note was corrected accordingly (it previously said PTLC "replaced the former Tender Board," which overstated what the Decree says).
- **Takamul programme/certificate** (Bahrain) — `تكامل`. Confirmed: Asharq Al-Awsat (a major pan-Arab newspaper, independent of Bahrain's own government) refers to the program as `برنامج «تكامل»` in its own Arabic reporting, matching the transliteration already used in this file.
- **Bahrain Tender Board** — **Resolved, Round A.3 D6 (22 Oct 2026).** The official Arabic organizational name is `مجلس المناقصات والمزايدات`, confirmed directly from a primary tenderboard.gov.bh Arabic HTML page (`https://www.tenderboard.gov.bh/Ar/AboutUs/Overview`), whose footer reads `مجلس المناقصات والمزايدات - مملكة البحرين`. This is an HTML page, not a PDF header, per this round's own instruction. A second confirmation attempt against `https://www.tenderboard.gov.bh/Ar` was blocked by an unanswered access-permission prompt that timed out before this pass could retry it -- disclosed rather than silently dropped, but the one successful fetch already meets the brief's own bar (a primary Arabic HTML page, exact URL, exact quoted text). All four Bahrain programs' `sourceNoteAr` (and the Bahrainisation workforce recommendation string) were updated from the former descriptive phrase `هيئة المناقصات البحرينية` / `هيئة المناقصات` to `مجلس المناقصات والمزايدات`, with the surrounding verb/pronoun agreement switched from feminine (`هيئة`) to masculine (`مجلس`) throughout (e.g. `تنشر الهيئة` → `ينشر المجلس`, `تطلبها الهيئة` → `يطلبها المجلس`).
- **Qatar Ministry of Finance policy title** — the English title "General Policy and Strategy for National Local Content" is sourced to Qatar's state news agency (qna.org.qa); this round's search located mof.gov.qa's own site but did not surface the policy's exact Arabic-language official title text within the search results available. The file's Arabic rendering, `السياسة العامة والاستراتيجية الوطنية للمحتوى المحلي`, is a direct, literal translation of the confirmed English title rather than a citation of the Ministry's own Arabic-language document — **not independently verified against the Ministry's own Arabic text this round**. Needs native-speaker / primary-source confirmation.
